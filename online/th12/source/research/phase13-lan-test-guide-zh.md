# TH12 双人局域网验收指南

## 1. 测试前准备

两台电脑各放置一份完整且相同的游戏目录。必须确认以下文件一致：

- `th12.exe`：日文版 1.00b；
- `th12_coop.dll`；
- `dinput8.dll`；
- `coop-launcher.exe`；
- `coop/config.ini` 中除启动器写入项以外的补丁开关。

两台电脑连接同一个局域网。主机在 Windows 的 `ipconfig` 输出中找到当前
网卡的 IPv4 地址，例如 `192.168.1.10`。Windows 防火墙需要允许
`th12.exe` 使用所选 UDP 端口，默认端口为 `28765`。

## 2. 图形启动器设置

主机：

1. 双击 `coop-launcher.exe`。
2. 选择“创建房间 (P1)”。
3. 设置房间号、UDP 端口、延迟帧和冗余帧。
4. 点击“启动游戏”。

客户端：

1. 双击 `coop-launcher.exe`。
2. 选择“加入房间 (P2)”。
3. 输入主机的局域网 IPv4 地址。
4. 填写与主机完全相同的房间号、端口、延迟和冗余。
5. 点击“启动游戏”。

首轮测试使用 `delay=3`、`redundancy=8`。主机控制逻辑 P1，客户端控制逻辑
P2；两边在游戏内都使用原版方向键、`Shift`、`Z`、`X`。主机在原版选机页
选择 P1，客户端在原版选机页选择 P2；双方仍需手工选择相同的游戏模式、难度
和路线，并进入同一关卡。

## 3. 分步验收

### A. 建立连接

双方进入关卡后应短暂等待并继续运行，不出现网络错误框。两边的
`coop/logs/patch.log` 都必须出现：

```text
phase13 LAN handshake complete; lockstep input application enabled
```

同一日志中的启动行必须包含 `network_apply=1`，且双方 timeline 编号一致。

### B. 输入归属

1. 主机只按方向键、低速、射击和 Bomb，确认只有 P1 响应。
2. 客户端执行同样操作，确认只有 P2 响应。
3. 双方同时向相反方向移动并射击，确认两个画面中的位置和动作一致。

验收标准：任何一台电脑的本地输入都不能同时控制两个逻辑玩家，也不能控制
错误的玩家。

### C. 游戏状态一致性

至少完整游玩一个 Boss 阶段，依次覆盖：

- 两人同时射击和同时 Bomb；
- P1、P2 分别中弹、复活、擦弹和收取道具；
- Power、残机、Bomb、碎片、UFO 和分数变化；
- Boss 非符和符卡阶段，双方画面的 HP 与阶段切换一致。

验收标准：两台电脑逐项显示一致，敌人死亡和弹幕消除发生在同一时刻，持续
游玩 10 分钟不出现 `State verification failed`。

### D. 暂停、抖动和断线

1. 任意一方按 `Pause`，双方应停在帧边界；同一方再次按下后双方恢复。
2. 暂时断开客户端网络 1 至 3 秒后恢复，双方应等待并继续，不能预测运行。
3. 再测试断开超过 5 秒，另一方应显示网络错误并终止本局。

暂停日志应成对出现：

```text
phase13 lockstep paused at frame boundary
phase13 lockstep resumed at frame boundary
```

### E. 时间线重置

依次测试重开关卡、续关、完成一关和返回标题。每次重新进入关卡后再次执行相反
方向的移动测试。

验收标准：不读取上一局残留输入，不崩溃，双方新 timeline 一致。

## 4. 失败时需要保留的材料

出现不同步、卡死、闪退或错误框时，两台电脑都不要再次启动游戏，以免日志被
后续运行混入。分别保留并标明主机/客户端：

- `coop/logs/patch.log`；
- `coop/logs/bootstrap.log`；
- `coop/logs/launcher.log`；
- 错误框完整文字；
- 首次出现差异时的关卡、Boss 阶段和双方操作。

首次联机只需完成 A、B 和连续移动射击 2 分钟。通过后再执行 C 至 E，便于把
连接问题和游戏状态不同步分开定位。
