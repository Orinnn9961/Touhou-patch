# 双机控制契约

本项目的最终控制方向固定如下，后续锁步、Bomb 和共享资源阶段不得改变这些语义：

| 进程身份 | 本机物理按键 | 逻辑玩家 |
|---|---|---|
| 主机 | 方向键、Shift、Z、X | P1 |
| 客户端 | 方向键、Shift、Z、X | P2 |

物理键只在每台电脑本地采样。网络传输的是 TH12 动作位，不传虚拟键码：

| 动作 | 位值 |
|---|---:|
| 射击 | `0x01` |
| Bomb | `0x02` |
| 低速 | `0x08` |
| 上 | `0x10` |
| 下 | `0x20` |
| 左 | `0x40` |
| 右 | `0x80` |

方向位来自 TH12 `0x004364F0` 的实际分支，不按数值顺序猜测。发送和接收时均原样保留位值，不旋转、不镜像、不交换上下或左右。

`BuildRoleScopedFrameInput` 强制主机输入只进入 P1 槽、客户端输入只进入 P2 槽。`MergeRoleScopedFrameInputs` 只接受相同帧号且槽位互斥的两份输入。UDP 握手同时校验身份与玩家号，主机/P1 或客户端/P2 对应错误时不会建立可用输入流。

当前 `network_mode=off` 仍保留单机调试键位：P1 使用原版键位，P2 使用 WASD/Space/J/K。它只用于同机人工测试，不属于网络协议。网络模式下，两台电脑都从各自的原版方向键、Shift、Z、X生成本机动作，再按会话身份放入逻辑 P1 或 P2。

Bomb 位已经进入输入掩码与网络帧，但在 Bomb 隔离完成前不会触发 P2 Bomb。远程输入写回模拟仍须等确定性和固定延迟锁步完成后启用。
