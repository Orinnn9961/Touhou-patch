东方绀珠传 1.00b 四自机零半径判定补丁 v3.1
================================================

功能
----
将灵梦、魔理沙、早苗、铃仙以及基于相同碰撞布局制作的兼容自机改版的中弹判定半径视为 0.0。
自机自身的判定缩为中心点；敌弹、激光仍保留自己的判定尺寸，因此不是无敌补丁。

v3.1 只修改真正的中弹内圈比较，角色公共半径表和擦弹外圈计算保持原值，因此擦弹范围与日文原版一致。
圆形、轴对齐矩形和旋转矩形/激光碰撞路径均已处理。

v3.1 修正了 v3.0 把旋转矩形/激光的擦弹外圈预筛误当成中弹比较的问题。v3.0 会缩小擦弹范围，并可能导致激光无法擦弹，请升级到 v3.1。

兼容范围
--------
不再要求整个 EXE 的 SHA-256 等于日文原版，而是在写入前检查：

- 目标是 32 位 x86 PE，映像基址和代码/数据映射与 TH15 1.00b 一致；
- 所有 18 个 v3.1 中弹修改点和 18 个 v3.0 迁移检查点保持已知字节；
- 其他魔改没有占用本补丁所需位置。

适用于日文原版 TH15 1.00b，以及只修改其他互不冲突位置、碰撞布局不变的魔改 EXE。
按当前要求不考虑汉化版；未对 th15c.exe 做兼容保证。

若某个改版重新编译或移动碰撞函数、改变映像布局，安装器会在写入前拒绝并指出冲突点，不会强行修改。

安装顺序
--------
先安装自机、功能等其他 EXE 补丁，最后安装零判定补丁。

以后升级其他补丁时：先运行 restore_original.cmd，只还原零判定修改；升级其他补丁；再运行 apply_patch.cmd。

使用方法
--------
方法一：把补丁目录中的全部文件放到 th15.exe 所在目录，双击 apply_patch.cmd。
方法二：把 th15.exe 或兼容魔改 EXE 拖到 apply_patch.cmd 上。

成功后会生成安装前版本的备份：

目标文件名.hitbox-zero.prepatch.<安装前SHA-256>.bak

备份按安装前哈希区分。魔改不同，补丁后的 SHA-256 不同，属于正常现象。

还原方法
--------
把已应用 v3.1 的 EXE 拖到 restore_original.cmd 上；补丁文件与 th15.exe 同目录时也可直接双击。

还原只反向恢复检测到的 v3.1 或 v3.0 修改字节，不会用日文原版覆盖其他互不冲突的魔改。若同一批位置后来又被其他工具修改，脚本会拒绝自动还原。

旧版迁移
--------
早期版本直接把文件偏移 0xCC1B0 的公共半径表清零，导致擦弹范围也改变。v3.1 检测到该格式时，会先恢复灵梦 2.0、魔理沙 3.0、早苗 3.0、铃仙 3.0，再安装只影响中弹的逻辑。

如果目标已经应用有擦弹问题的 v3.0，直接运行 v3.1 的 apply_patch.cmd 即可。脚本会识别完整的 v3.0，先撤销其 18 处修改，再应用 v3.1；不需要手动还原。

旧版生成的 .hitbox-zero.original.bak 不会自动删除。v3.1 使用带安装前 SHA-256 的 prepatch 备份名。

实现信息
--------
TH15 的圆形和矩形碰撞代码会先判断中弹内圈与擦弹外圈。v3.1 只把内圈计算使用的自机半径或半宽/半高副本置零，不需要注入额外代码。

旋转矩形/激光路径先用自机半宽/半高的 16 倍做擦弹外圈预筛，再用原始尺寸区分中弹和擦弹。v3.1 保留前一组外圈读取，只把后一组中弹比较改为中心点比较。

文件范围与测试
--------------
补丁只修改传入的目标 EXE，并在其旁创建备份；不修改 DAT、存档、Replay、音乐或其他游戏文件。
本版本已做脚本解析、逐点字节、原版安装/还原和 v3.0 直接迁移验证；游戏内行为由使用者手动测试。

分享与 Replay 注意事项
----------------------
分享本补丁目录即可，请勿把游戏 EXE、DAT、音乐或其他原作文件放入压缩包。
观看 Replay 的双方应使用相同游戏改版和零判定状态。交流成绩或录像时应明确标注使用了零半径判定补丁。
