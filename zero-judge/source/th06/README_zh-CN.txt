东方红魔乡 自机零判定补丁
========================

功能
----
将灵梦与魔理沙的自机中弹判定矩形半宽从 1.25 x 1.25 改为 0.0 x 0.0，使自机自身的判定缩为中心点。敌弹、激光和敌机仍保留各自的判定大小，因此这不是无敌补丁。

支持版本
--------
仅支持本目录提供的日文 th06.exe，其游戏代码对应 1.02h，但数据文件名已改为 th06_*.DAT，因此整文件哈希不同于官方未改动的 1.02h EXE。

支持的原始 SHA-256：
327C4E923D7057D80D3057AED1E60389F4B560FABCEC73C9DBB956EA68EC52AB

补丁版 SHA-256：
C2565B2A68FEFBB7614BB2D055C8B54ADA07ADD63343BF1BA52EB403EB235DB6

不支持 th06c.exe、名为“東方紅魔郷.exe”的汉化版、官方未改动哈希、其他版本或已有其他修改的 EXE。脚本会先检查完整文件哈希，不符合时不会写入。本补丁不修改任何 DAT、存档、Replay、音乐或其他文件。

使用方法
--------
方法一：把补丁包中的 4 个文件放到 th06.exe 所在目录，双击 apply_patch.cmd。
方法二：把 th06.exe 拖到 apply_patch.cmd 上。

首次成功应用后会自动生成：
th06.exe.hitbox-zero.original.bak

还原方法
--------
把 th06.exe 拖到 restore_original.cmd 上；如果补丁文件就在游戏目录，也可以直接双击。
还原脚本只处理由本补丁生成的 EXE，不会覆盖其他未知修改。

修改内容
--------
文件偏移 0x29DC8：00 00 A0 3F (1.25f) -> 00 00 00 00 (0.0f)
文件偏移 0x29DD5：00 00 A0 3F (1.25f) -> 00 00 00 00 (0.0f)

两处立即数位于自机初始化函数（运行时地址 0x00429DC8 与 0x00429DD5），分别写入判定矩形的 X、Y 半宽。后续普通弹幕、激光和敌机接触判定都使用由这两个字段生成的边界。Z 维的 5.0 保留不变，因为游戏的中弹检测只比较 X、Y。

分享与录像注意事项
------------------
分享本补丁包即可，请不要把 th06.exe、游戏 DAT、音乐或其他原作文件放进压缩包。
补丁改变游戏规则。旧 Replay 可能不同步；使用补丁录制的 Replay 也应在相同补丁状态下播放。交流成绩或录像时应明确标注使用了零判定补丁。
