东方星莲船 1.00b 三自机零半径判定补丁 v3.0
================================================

功能
----
将灵梦、魔理沙、早苗以及基于这些配置制作的兼容自机补丁的中弹判定半径视为 0.0。
自机自身的判定缩为中心点；敌弹、激光仍保留自己的判定尺寸，因此不是无敌补丁。

本补丁只修改真正的中弹比较，保留原版擦弹范围。圆弹、矩形弹和旋转矩形/激光碰撞路径均已处理。

兼容范围
--------
v3.0 不再要求整个 EXE 的 SHA-256 等于日文原版，而是检查以下兼容条件：

- 32 位 x86 PE，映像基址和代码/数据映射与 TH12 1.00b 一致；
- 所有碰撞函数、命中调用点和注入空间均保持已知原始字节，或已经完整应用本补丁；
- 其他补丁没有占用零判定补丁所需的代码和数据位置。

已验证输入：

- 日文原版 TH12 1.00b；
- 基于相同代码布局的中文版 th12c.exe；
- TH12 日文版灵梦B -> 妖梦自机补丁 v3.0/v3.1；
- 只修改其他互不冲突位置的 1.00b EXE 改版。

“兼容”不等于盲目修改任意文件。若某个版本重新编译、移动碰撞函数、改变映像布局，或已有补丁占用相同位置，安装器会在写入前拒绝并指出冲突点。

安装顺序
--------
先安装汉化、自机、功能等其他补丁，最后安装零判定补丁。

如果以后需要升级妖梦或其他 EXE 补丁：

1. 先运行 restore_original.cmd，只还原零判定修改；
2. 升级其他补丁；
3. 再运行 apply_patch.cmd 重新应用零判定。

不要让其他安装器从原版备份重建 EXE 后继续沿用旧的零判定状态；重建后应重新运行本补丁。

使用方法
--------
方法一：把补丁包中的全部文件放到目标 EXE 所在目录，双击 apply_patch.cmd。
方法二：把 th12.exe、th12c.exe 或兼容改版 EXE 拖到 apply_patch.cmd 上。

成功后会在目标旁生成当前输入版本的备份：

目标文件名.hitbox-zero.prepatch.<安装前SHA-256>.bak

备份按安装前哈希区分，因此同一目录可以安全保留原版、汉化版和不同自机补丁版本的备份。补丁后 SHA-256 会按实际输入动态显示；不同改版得到不同哈希是正常现象。

还原方法
--------
把已经应用零判定的 EXE 拖到 restore_original.cmd 上；如果补丁文件就在目标目录，也可以直接双击。

v3.0 只反向恢复本补丁修改的字节，不会用日文原版覆盖妖梦、汉化或其他互不冲突的修改。还原后若没有其他后续修改，安装器会按还原结果哈希找到对应 prepatch 备份并确认一致。

若应用零判定之后又有其他工具修改了同一批碰撞位置，自动还原会拒绝执行，避免破坏未知补丁。

旧版迁移
--------
旧版将文件偏移 0xB21A8 的角色公共半径表直接改为 0。v3.0 检测到该旧格式时会先恢复灵梦 2.0、魔理沙 3.5、早苗 3.0，再安装只影响中弹的新版逻辑。

旧版生成的 th12.exe.hitbox-zero.original.bak 不会自动删除。v3.0 使用新的带 SHA-256 的 .hitbox-zero.prepatch.*.bak 名称，以区分“日文原版备份”和“任意兼容改版的安装前备份”。

实现信息
--------
补丁分别修改圆形、轴对齐矩形和旋转矩形/激光的中弹路径。旋转碰撞先保留原结果；只有原结果为中弹时，才以零半径复核。复核未命中会转为擦弹，从而保留原擦弹范围及相关状态更新。

hitbox_patch.asm 是注入机器码的可读源文件，仅供审计；运行补丁不需要安装编译器。

分享与 Replay 注意事项
----------------------
分享本补丁包即可，请不要把 th12.exe、th12c.exe、游戏 DAT、音乐或其他原作文件放进压缩包。

观看 Replay 的双方必须使用相同的游戏、自机补丁和零判定规则。原版 Replay 若实际依赖一次中弹，结果会改变；旧版零半径补丁录制的 Replay 也可能因旧版擦弹范围不同而失步。

游戏本身、vpatch 或其他改版引起的 Replay 失步不在本补丁的修复范围内。交流成绩或录像时应明确标注使用了零半径判定补丁。
