东方地灵殿 1.00a 双自机零半径判定补丁 v3.0
================================================

功能
----
将灵梦、魔理沙以及基于相同碰撞布局制作的兼容自机改版的中弹判定半径视为 0.0。
自机自身的判定缩为中心点；敌弹、激光仍保留自己的判定尺寸，因此不是无敌补丁。

v3.0 只修改真正的中弹比较，角色公共半径表保持原值，因此擦弹范围与日文原版一致。
圆形、轴对齐矩形和旋转矩形/激光碰撞路径均已处理。

兼容范围
--------
不再要求整个 EXE 的 SHA-256 等于日文原版，而是在写入前检查：

- 目标是 32 位 x86 PE，映像基址和代码/数据映射与 TH11 1.00a 一致；
- 所有碰撞函数、命中调用点、注入空间保持已知原始字节，或已完整应用本补丁；
- 其他魔改没有占用本补丁所需位置。

适用于日文原版 TH11 1.00a，以及只修改其他互不冲突位置、碰撞布局不变的魔改 EXE。
按当前要求不考虑汉化版；未对 th11c.exe 做兼容保证。

若某个改版重新编译或移动碰撞函数、改变映像布局，安装器会在写入前拒绝并指出冲突点，不会强行修改。

安装顺序
--------
先安装自机、功能等其他 EXE 补丁，最后安装零判定补丁。

以后升级其他补丁时：先运行 restore_original.cmd，只还原零判定修改；升级其他补丁；再运行 apply_patch.cmd。

使用方法
--------
方法一：把补丁目录中的全部文件放到 th11.exe 所在目录，双击 apply_patch.cmd。
方法二：把 th11.exe 或兼容魔改 EXE 拖到 apply_patch.cmd 上。

成功后会生成安装前版本的备份：

目标文件名.hitbox-zero.prepatch.<安装前SHA-256>.bak

备份按安装前哈希区分。魔改不同，补丁后的 SHA-256 不同，属于正常现象。

还原方法
--------
把已应用 v3.0 的 EXE 拖到 restore_original.cmd 上；补丁文件与 th11.exe 同目录时也可直接双击。

还原只反向恢复 v3.0 修改的字节，不会用日文原版覆盖其他互不冲突的魔改。若同一批位置后来又被其他工具修改，脚本会拒绝自动还原。

旧版迁移
--------
旧版直接把文件偏移 0xA60A8 的公共半径表清零，导致擦弹范围也改变。v3.0 检测到该格式时，会先恢复灵梦 2.0、魔理沙 3.5，再安装只影响中弹的逻辑。

旧版生成的 .hitbox-zero.original.bak 不会自动删除。v3.0 改用带安装前 SHA-256 的 prepatch 备份名。

实现信息
--------
轴对齐矩形和圆形路径直接把中弹计算中的自机尺寸改为零。旋转碰撞先保留原结果；只有原结果为中弹时，才用零尺寸复核，复核未命中则保留为擦弹结果。

hitbox_patch.asm 是注入机器码的可读源文件，仅供审计；运行补丁不需要安装编译器。

文件范围与测试
--------------
补丁只修改传入的目标 EXE，并在其旁创建备份；不修改 DAT、存档、Replay、音乐或其他游戏文件。
本版本已做脚本解析、逐点字节和临时副本安装/还原验证；游戏内行为由使用者手动测试。

分享与 Replay 注意事项
----------------------
分享本补丁目录即可，请勿把游戏 EXE、DAT、音乐或其他原作文件放入压缩包。
观看 Replay 的双方应使用相同游戏改版和零判定状态。交流成绩或录像时应明确标注使用了零半径判定补丁。
