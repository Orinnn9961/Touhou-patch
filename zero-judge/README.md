# 零判 Hit-box 补丁

本目录收录各作品当前最新版的零判（自机判定点缩小/归零）补丁压缩包。

每个补丁的脚本源码位于 [`source/`](source/) 下对应的作品目录，包含补丁脚本、启动/恢复命令和必要的汇编源码。

## 使用注意

- 零判版本生成的 replay **不能与原版互通**；请使用相同补丁版本进行录制和回放。
- `v1.0` 版本通常会改变擦弹范围。
- `th12` 和 `th15` 的补丁不会改变擦弹范围，但它们生成的 replay 仍然不能与原版互通。
- 补丁只适用于对应作品和版本。使用前请备份游戏文件，并按压缩包内的 `README_zh-CN.txt` 操作。
